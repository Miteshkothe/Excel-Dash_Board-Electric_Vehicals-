# Electric Vehicle Data Analysis Project

## Overview

This project analyzes a dataset of electric vehicles (EVs) using Microsoft Excel. The goal is to gain insights into various aspects of the EV market, such as pricing, range, efficiency, and market trends. This analysis can be valuable for consumers, manufacturers, and policymakers interested in the growing EV industry.

## Dataset

The dataset used in this project is stored in an Excel file . It contains information about various EV models, including:

* **Make/Model:** The manufacturer and model of the vehicle.
* **Price (USD):** The retail price of the vehicle.
* **Range (Miles):** The estimated driving range on a single charge.
* **Efficiency (Miles/kWh):** The vehicle's energy efficiency.
* **Fast Charge Speed (Miles/Hour):** The speed at which the vehicle can be fast-charged.

## Project Structure

* `electric_vehicles.xlsx`: The raw data file.
* `analysis.xlsx`: An Excel file containing the analyzed data, including calculated metrics, charts, and pivot tables.
* `README.md`: This file, providing an overview of the project.

## Analysis Performed

The analysis in `analysis.xlsx` includes:

* **Descriptive Statistics:** Calculating mean, median, standard deviation, and other statistical measures for numerical columns.
* **Price Distribution:** Creating histograms and box plots to visualize the distribution of EV prices.
* **Range Analysis:** Analyzing the relationship between price and range, and identifying EVs with the best range per dollar.
* **Efficiency Comparison:** Comparing the efficiency of different EV models and manufacturers.
* **Market Trends:** Identifying popular EV models and brands.
* **Pivot Table Analysis:** Summarizing and analyzing data using pivot tables to show things like average range per maker.
* **Visualizations:** Creating charts and graphs to represent the data and insights.
* **Identifying outliers:** Finding any data that is far outside the other data points.
